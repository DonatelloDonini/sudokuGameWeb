Sudoku API

Play sudoku

Making a sudoku game and don't want to write a generator? This free API gives you puzzles with a single solution, graded by the techniques a person needs to solve them, plus a solver, a difficulty grader and step by step hints. No account or key needed.

Basics

  • Base URL: https://your-server/api/v1
  • Requests and responses are JSON. Every endpoint can be called from any website (CORS is open) and uses no cookies.
  • Puzzles can be sent and received in two formats, chosen with ?format=:
    • array (default): a 9x9 array indexed as puzzle[y][x], with null for empty cells (0 is accepted too);
    • string: 81 characters, row by row, with . for empty cells (0 is accepted too).
  • Coordinates in responses are x (column, 0-8) and y (row, 0-8).

GET /puzzles

New puzzles, generated on request, with their solution and grade.

ParameterDefaultDescription
difficultymediumeasy, medium, hard or expert (see difficulties)
count1How many puzzles, 1 to 10
formatarrayarray or string
 
curl "https://your-server/api/v1/puzzles?difficulty=hard&format=string"
{
  "puzzles": [
    {
      "difficulty": "hard",
      "puzzle": "..9.4...1.3...7..5...",
      "solution": "759842361831697245...",
      "emptyCells": 55,
      "hardestTechnique": "X-Wing",
      "score": 112,
      "techniques": { "Hidden single": 49, "Naked single": 3, "Pointing": 2, "X-Wing": 1 }
    }
  ]
}

techniques tells how many times each technique is used to solve the puzzle, easiest technique first. score adds them up with a weight per technique: higher is harder within the same difficulty.

POST /solve

Solves any puzzle, and tells whether its solution is unique.

curl -X POST "https://your-server/api/v1/solve" \
  -H "Content-Type: application/json" \
  -d '{"puzzle": "53..7....6..195....98....6.8...6...34..8.3..17...2...6.6....28....419..5....8..79"}'
{
  "solvable": true,
  "unique": true,
  "solution": [[5, 3, 4, 6, 7, 8, 9, 1, 2], ...]
}

When there are several solutions, unique is false and solution is one of them.

POST /grade

Grades any puzzle, yours included, the same way the generated ones are graded.

fetch("https://your-server/api/v1/grade", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ puzzle: myPuzzle }),
}).then(response => response.json());
{
  "solvable": true,
  "unique": true,
  "solvableWithLogic": true,
  "difficulty": "medium",
  "hardestTechnique": "Naked pair",
  "score": 74,
  "techniques": { "Hidden single": 51, "Naked single": 2, "Naked pair": 1 },
  "emptyCells": 51
}

difficulty is null when the puzzle doesn't have exactly one solution, or when it needs harder reasoning than the expert techniques (solvableWithLogic is then false).

POST /hint

Send the player's current board, get the next number a person could place and the technique that finds it. On hard puzzles a number can only be found after removing some candidates: steps lists those deductions, so you can explain the hint or show it on the player's notes. 

{
  "x": 2,
  "y": 2,
  "value": 9,
  "technique": "Hidden single",
  "steps": [
    { "technique": "Pointing", "eliminations": [{ "x": 8, "y": 7, "digits": [6] }] },
    { "technique": "XY-Wing", "eliminations": [{ "x": 8, "y": 2, "digits": [9] }, { "x": 7, "y": 6, "digits": [9] }] }
  ]
}

Boards with a wrong number answer 422, full boards 409. If logic alone can't progress, the hint is a correct number with "technique": null.

GET /difficulties

The difficulty depends on the reasoning a puzzle needs, not on how many cells are empty. Every puzzle of a difficulty needs at least one technique of its level and nothing harder:

DifficultyTechniques
easyhidden single, naked single (and at most 45 empty cells)
mediumpointing, box/line reduction, naked pair, hidden pair
hardnaked triple, hidden triple, X-Wing
expertXY-Wing, XYZ-Wing, Swordfish

Limits and errors

  • Each IP can make 60 requests per minute; every generated puzzle counts as one request. The RateLimit-Limit, RateLimit-Remaining and RateLimit-Reset headers tell where you are.
  • Over the limit the API answers 429 with a Retry-After header (in seconds). When too many puzzles are being generated it answers 503, also with Retry-After.
  • Errors are {"error": "message"}: 400 for invalid parameters or malformed puzzles, 422 for puzzles breaking the rules (a number repeated in a row, column or box).
  • Hard and expert puzzles take longer to generate (up to a few seconds for 10): if your game needs them often, keep a few in advance.
